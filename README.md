# Tugas2_Klasifikasi_Image_Menggunakan_CNN-
Implementasi klasifikasi citra menggunakan Convolutional Neural Network (CNN) dengan dataset dari Kaggle. Proyek ini mencakup eksplorasi data (EDA), pra-pemrosesan citra, pelatihan dan evaluasi model, serta visualisasi hasil klasifikasi melalui dashboard interaktif menggunakan Streamlit.
